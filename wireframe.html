2. Tech & "AI" approach (hackathon)

Real APIs
Google Maps JavaScript API · Places API (Nearby Search) · Directions · Geolocation. Key restricted by HTTP referrer.
Browser Web Speech API for 🔊 / 🎤 (free).
Dummy AI (algorithms)
• Chat: keyword + intent scoring over local JSON
• Plan: tag match + nearest-neighbour route
• Wait: time-table × holiday multiplier
• Menu: sample images + dictionary
• Phrases: sorted by local usage count
Static data (JSON)
phrases.json (EN/NP/JP/hiragana/romaji) · spots.json · emergency.json · trash.json · menu_dict.json · ui_strings.json (i18n)
Stack suggestion
Plain HTML + CSS + vanilla JS (or React + Vite) · PWA (offline phrases & SOS) · deploy on Cloudflare Pages / GitHub Pages — no backend needed.
Honesty labels
Small badge on AI / Menu / Wait / Plan: DEMO – NOT REAL AI. Footer: "Prototype for hackathon, data are sample."
